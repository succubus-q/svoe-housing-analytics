Особенности API: ставка в другой публикации, месяц выдач отличается от `date`,
остатки являются состоянием на дату, валютные столбцы нельзя складывать,
`units` — общий справочник, ID ЦБ — не коды субъектов РФ.
Подробности и исходные ограничения: `cbr-api-research.md`.

После этапа 1 дополнительно проверены 2025–2026 годы и четыре настроенных разреза
по всем шести метрикам. Полнота по всем 96 разрезам не заявляется.
