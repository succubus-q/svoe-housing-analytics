# Ограничения и подготовка к production

Текущее состояние подтверждается [кодом](repository-map.md) и
[финальным ревью](../final-review.md). Последний столбец — план будущих работ,
а не уже реализованные функции.

| Ограничение MVP                                              | Почему допустимо для конкурсного MVP                                                              | Что потребуется для production                                                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Четыре настроенных разреза                                   | Достаточно для демонстрации полного цикла и сравнения территорий                                  | Исследовать каждый дополнительный measure, полноту и иерархию, расширить CBR_REGIONS и проверки                      |
| Нет заявления о полном историческом/региональном покрытии    | Исследование и импорт проверены в ограниченном диапазоне, default fromYear=2025                   | Проверить годы и смены методологии для каждого ряда, определить SLA полноты и мониторинг пробелов                    |
| Crash recovery после lease и следующего запуска              | Lease 60 секунд освобождает владение после аварии без ручной правки                               | Определить требуемое время восстановления, добавить наблюдение за просроченными запусками и управляемый повтор       |
| Нельзя немедленно записать FAILED в полностью недоступную БД | Физически недоступное хранилище не принимает даже журнал ошибки, исключение сохраняет обе причины | Внешние логи/алерты, стратегия отказоустойчивости БД и сверка незавершённых запусков после восстановления            |
| Atomic write ограничен 30 секундами                          | Проверено на объёме MVP, ограничивает удержание транзакции                                        | Измерить большие объёмы, оптимизировать пакетную запись или staging, сохранив owner fencing и атомарность публикации |
| Нет визуальных browser E2E                                   | Есть unit, SQL/API integration, build и HTTP smoke                                                | Добавить браузерные сценарии фильтров, графиков, ошибок, ручного sync и CSV, визуальную регрессию                    |
| Administrative sync без авторизации                          | Compose слушает loopback, сценарий локальный                                                      | Аутентификация, роль администратора, аудит, ограничения частоты и защита доступа по требованиям площадки             |
| Нет XLSX fallback                                            | Все шесть целевых показателей подтверждены через REST                                             | При необходимости отдельно исследовать официальный экспорт, формат, методологию и идемпотентное сопоставление        |
| Другие показатели банковского сектора не реализованы         | MVP закрывает ипотечную часть конкурсной задачи                                                   | Согласовать новые метрики, проверить API-контракты, добавить определения, mapper и тесты                             |
| Нет гарантии SLA/графика публикаций ЦБ                       | Приложение ежедневно перепроверяет месячные ряды                                                  | Определить допустимую задержку, мониторить свежесть каждого ряда и согласовать режим запросов с источником           |
| Raw archive не имеет политики очистки                        | Подходит для ограниченной локальной демонстрации                                                  | Ввести retention, контроль объёма, доступов и связь диагностики с запуском                                           |
| Частичный импорт допускается                                 | PARTIAL сохраняет пригодные данные с issues без выдачи частичного результата за полный            | Определить пороги полноты, правила публикации сводок и алерты по каждому ряду                                        |

Защита от дублей проверена при существующей схеме и правилах преобразования.
При добавлении других валют/источников потребуется пересмотреть ключ наблюдения:
сейчас он не включает валюту и source, поскольку MVP импортирует один RUB-контур.

Факт интеграции с промышленным порталом Россельхозбанка, нагрузочное SLA,
экономический эффект и полная готовность к публичной эксплуатации не заявляются.
