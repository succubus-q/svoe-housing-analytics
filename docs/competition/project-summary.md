# Система автоматического сбора аналитических данных для портала «Своё Жильё»

## Конкурсная задача

Разработать систему API-интеграции для регулярного получения, обработки и подготовки
аналитических данных Банка России по ипотечному жилищному кредитованию и банковскому
сектору. Реализованный MVP охватывает ипотечную часть задачи: шесть исходных метрик
в четырёх настроенных территориальных разрезах. Другие показатели банковского сектора
остаются направлением развития.

## Проблема

Официальная статистика доступна, но её внешний формат не готов для непосредственного
использования в аналитическом интерфейсе портала. Показатели находятся в разных
публикациях, содержат валютные колонки и разные обозначения периода. Порталу нужен
регулярно обновляемый слой с едиными единицами измерения, понятной методологией,
историей загрузок и стабильным внутренним API.

## Решение

Модульный монолит на Node.js, TypeScript и Fastify получает данные официального
Data Service API Банка России. Адаптер проверяет публикации и datasets, mapper
выбирает рублёвые строки, приводит суммы к рублям, проверяет период и сохраняет
источник наблюдения. PostgreSQL и Prisma обеспечивают хранение и уникальность.
Analytics API отдаёт нормализованные ряды и сводку React dashboard.

Scheduler проверяет источник ежедневно в 05:00 UTC, то есть в 08:00 по Москве
при настройках по умолчанию. Возможны импорт при старте и ручной запуск. Данные
имеют месячную периодичность: ежедневная проверка не означает ежедневную статистику.

## Результат MVP

- Шесть метрик ЦБ: количество и объём ИЖК, средневзвешенные ставка и срок,
  задолженность и просроченная задолженность. Все ряды относятся к RUB.
- Средний размер кредита, MoM и YoY рассчитываются на стороне приложения.
- Dashboard показывает фильтры региона/месяца, карточки, три графика, месячную таблицу,
  CSV и сведения об источнике и синхронизации.
- Импорт использует upsert и сравнение содержимого. SyncLog фиксирует результат,
  счётчики и замечания. Lease/heartbeat и проверка владельца защищают от параллельной записи.
- Первичный живой импорт в отдельном чистом стенде дал 480 наблюдений из 1280 строк.
  Повторный импорт не создал и не обновил записи, число наблюдений осталось 480.
- Предыдущее ревью и повторные проверки приведены в [testing](testing.md).

Ценность для «Своего Жилья» — подготовленный аналитический слой для будущего раздела
портала и воспроизводимый процесс обновления официальной статистики. Внедрение в
системы банка, экономия времени в процентах и коммерческие эффекты не измерялись.
