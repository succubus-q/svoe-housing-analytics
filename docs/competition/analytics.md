# Реализованная аналитика

Все исходные ряды относятся к рублёвому сегменту. Внутренний API возвращает
числа в единицах БД, а dashboard масштабирует суммы для читаемого отображения.
Ставки и сроки публикует ЦБ как средневзвешенные. Приложение не вычисляет их
повторно и не усредняет разные регионы.

| Показатель                 | Источник publication/dataset                     | Хранение или расчёт                                 | Единица                    | Ограничение                                                                  |
| -------------------------- | ------------------------------------------------ | --------------------------------------------------- | -------------------------- | ---------------------------------------------------------------------------- |
| Количество ИЖК             | 21/44, colId 36                                  | MortgageObservation, MORTGAGE_COUNT                 | Кредиты, шт.               | Месячные выдачи, целое неотрицательное значение                              |
| Объём ИЖК                  | 21/45, colId 36                                  | MORTGAGE_VOLUME, исходное × 1 000 000               | RUB                        | Месячный объём выдач, без иных валют                                         |
| Средневзвешенная ставка    | 15/34, colId 36                                  | AVERAGE_RATE напрямую из ЦБ                         | % годовых                  | Нулевую среднюю mapper пропускает                                            |
| Средневзвешенный срок      | 21/48, colId 36                                  | AVERAGE_TERM напрямую из ЦБ                         | Месяцы                     | Нулевую среднюю mapper пропускает                                            |

## Формулы

Пусть V(t) — объём в RUB, N(t) — количество за месяц t в том же регионе.

```text
Средний размер кредита(t) = V(t) / N(t), если N(t) > 0
MoM(t) = (X(t) − X(t−1)) / X(t−1) × 100%
YoY(t) = (X(t) − X(t−12)) / X(t−12) × 100%
```

При отсутствии/неконечности данных или нулевой базе сравнения функции возвращают
`null`. Для среднего дополнительно отвергаются отрицательный объём и количество ≤ 0.
Для MoM/YoY берётся точный календарный месяц, а не предыдущая имеющаяся строка.
Средний размер кредита получает собственные MoM и YoY по тем же формулам.

Для ставки и срока изменение тоже относительное. Например, ставка 10% → 12%
даёт MoM +20%, а не +2 процентных пункта. Это арифметический пример формулы,
он не описывает наблюдение из ЦБ. Суммирование остатков по месяцам и усреднение
территориальных средних не реализованы и методологически не предлагаются.

## API и dashboard

| Endpoint                                                         | Назначение                                                 |
| ---------------------------------------------------------------- | ---------------------------------------------------------- |
| GET /api/v1/regions                                              | Только разрезы с импортированными наблюдениями             |
| GET /api/v1/mortgage/stats?region=CBR-22&from=2025-01&to=2026-08 | Отсортированные нормализованные ряды, опционально metric   |
| GET /api/v1/mortgage/summary?region=CBR-22                       | Последний доступный месяц, все метрики и сравнения         |
| GET /api/v1/mortgage/summary?region=CBR-22&period=2026-08        | Явно выбранный месяц, если он доступен                     |
| GET /api/v1/sync/status                                          | Последний запуск, счётчики, running, количество наблюдений |
| POST /api/v1/sync/run                                            | Ручной запуск с ожиданием итогового SyncLog                |
| GET /health                                                      | Проверка backend и доступности PostgreSQL                  |

В OpenAPI шесть бизнес/health endpoints: три mortgage/regions, два sync и health.
`/docs` и `/docs/json` обслуживают документацию и не входят в эти шесть.
Формат месяца — YYYY-MM; некорректные параметры дают 400, неизвестный регион или
недоступный месяц сводки — 404. Для stats максимальный диапазон — 25 лет, хотя
это не гарантия наличия 25 лет данных.

Dashboard показывает карточки и MoM, три графика (объём, количество, ставка),
таблицу месяцев и CSV. YoY объёма выдач отображается в блоке динамики. Годовые сравнения остальных метрик
доступны через API. Кредитный портфель и просроченная задолженность показаны
под карточками и доступны в API и CSV. Таблица отображает
средний кредит, а суммы в карточках/графиках масштабированы в млрд/млн рублей.

`availablePeriods` объединяет месяцы с любыми наблюдениями выбранного региона,
поэтому самый поздний месяц не обязательно содержит все шесть метрик.
`sourceUpdatedAt` сводки — максимальное время dataset среди строк текущего месяца,
не гарантия свежести каждого ряда. Отсутствие значения означает null, а не ноль.
