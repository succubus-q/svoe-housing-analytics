## Материалы проекта

Для защиты: прочитать краткое описание, открыть содержание презентации, отрепетировать
речь и ответы. Слайды содержат только проверенные технические результаты. Измеренного
бизнес-эффекта и факта внедрения в портал банка не заявляем.

Для технической проверки: начать с [корневого README](../../README.md), затем изучить
архитектуру, поток данных и testing. Все команды выполняются из корня проекта.

Для передачи: итоговые ZIP и отдельные материалы формируются в
`artifacts/competition/` рабочей папки. Сам ZIP не включает себя и соседние артефакты.
Источники диаграмм находятся в
[`assets/competition/diagrams/`](../../assets/competition/diagrams/).
ZIP материалов можно распаковать отдельно: он сохраняет пути `docs/`, `assets/`,
`src/`, `tests/`, `prisma/` и curated evidence, на которые ссылаются документы.

0 обновлено, 800 пропущено. Повторный импорт сохранил 480 записей без дублей.
